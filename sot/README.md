# sot

Source of truth for the Kadena Chainweb ecosystem. Released as a signed
binary from a private source repository.

## Install

    brew tap AI-KDA-Community/tap
    brew install sot

## Direct download

- macOS (Intel):          sot_0.1.1_darwin_amd64.tar.gz
- macOS (Apple Silicon):  sot_0.1.1_darwin_arm64.tar.gz
- Linux (x86_64):         sot_0.1.1_linux_amd64.tar.gz
- Linux (arm64):          sot_0.1.1_linux_arm64.tar.gz

Latest release:
https://github.com/AI-KDA-Community/releases/releases/tag/v0.1.1

Each release includes checksums.txt for verification.
